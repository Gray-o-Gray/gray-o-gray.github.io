# 给 AI 换模型前，先看懂这三个参数

问一句，等 100 秒。

<!-- more -->

这是我上周给自家的 AI 教练换了个「更强」的模型之后，它的新速度。

我本来只想让它想得更深一点。它确实开始说一些以前说不出的话了——但每次开口前，都要先沉默将近两分钟。

我第一反应是网络抽了。查了一圈才发现，模型选型根本不是症结，真正的问题在三个参数上：思考的开关、思考的档位，和一个会偷吃你正文的额度上限。

这三个东西不是 DeepSeek 独有的。凡是带推理能力的模型服务，基本都有对应的旋钮。所以这篇不聊哪家强，只聊换模型之前该看什么。

---

## 一、先别急着换，先查它还在不在

我的 AI 教练用 `deepseek-chat` 用了几个月，一直很稳。

出问题那天我想让它想得更深，就换成了 `deepseek-reasoner`。推理能力确实上来了，回答里开始出现交叉核对。但单轮耗时从几秒变成了大约 100 秒。

我去翻官方文档想找调参建议，结果先看到这么一件事：

官方模型列表里，只剩下 `deepseek-flash` 和 `deepseek-v4-pro`。

我一直在用的 `deepseek-chat`，和我刚换上去的 `deepseek-reasoner`，**都不在列表上了**。

也就是说，这两个模型现在的状态是：还能调，但已经不在名单里。

这件事比慢 100 秒更让我后背发凉。你写进代码里的那个模型名，不会有人发邮件通知你它要下线。它只会某天开始变慢、变贵，或者干脆报错。

所以换模型的第一步，不是比较谁更强。是去官方的 Models & Pricing 页面看一眼：我现在这个，还在不在。

---

## 二、thinking：思考是个开关，不是一种模型

我以前的认知是错的——我以为想要推理能力，就得换推理模型。

现在不是这样了。思考是一个开关，跟模型本身解耦：

```json
"thinking": { "type": "enabled" }   // 开启
"thinking": { "type": "disabled" }  // 关闭
```

麻烦的是，它**默认是开启的**。

这意味着一件特别容易被忽略的事：你可能一直以为自己在用「普通模式」，其实它一直在思考。那些延迟和 token 消耗，也一直在发生。

所以「我这次调用到底有没有在思考」不能靠感觉，得看参数。

---

## 三、reasoning_effort：想少一点，调档就行

我的 100 秒就是靠这个解决的。

既然思考分档，那「我想让它想，但别想那么久」就不用二选一了：

```json
"reasoning_effort": "low"   // 轻量思考
"reasoning_effort": "high"  // 默认档
"reasoning_effort": "max"   // 最重
```

官方还收几个别名，`minimal` 归到 `low`，`medium` 和 `xhigh` 归到 `high`，`ultra` 归到 `max`。

我拿同一个问题、同样大约 11k 字符的上下文跑了一遍：`deepseek-reasoner`，就是我一开始换的那个，大约 100 秒；换成 `deepseek-flash` 配 `low`，大约 10 秒；配 `high`，大约 9 秒；把思考关掉，最快。

等一下——`low` 是 10 秒，`high` 是 9 秒？

对，我当时也愣了一下。这说明强度档位不是「越慢越强」的线性关系。简单的问题，两档根本拉不开差距；真正复杂的题，差距才会出来。

所以我没有全局统一，而是按用途分。教练对话是自由问答，要判断，我给 `high`，愿意多等。每周分析要跨好几天的数据做权衡，本来就要跑一两分钟，也用 `high`。按天反馈每天自动跑一次，频次高，快比深重要，我给 `low`。

这套分档，比「统一换一个更强的模型」管用得多。

---

## 四、max_tokens：思考和正文抢同一份饭

这是三个参数里最阴的一个。

我试着把 `max_tokens` 设成 1500，当时想的是「我只要几百字的回答，够了」。

结果返回是空的。

我盯着那个空回复看了半天，第一反应是提示词写崩了。后来去看返回内容才发现：光思考就用了 2322 个 token。

已经超过我设的 1500 了。额度被思考吃光，正文一个字都没轮到。

你可以把 `max_tokens` 想成一桌饭的预算。思考和正文同桌吃饭，思考先动筷子，它吃饱了，正文就只能干看着。

所以那句规则是：**思考 token 计入 `max_tokens`，你给的上限是「思考 + 正文」的总和，不是正文的长度。**

下次遇到「AI 明明在转，最后却什么都没说」，先别怀疑提示词，去看看 `max_tokens` 是不是给小了。我现在直接给到 8000，反正上限只是封顶，不代表每次都会用满。

顺带一个同源的坑：思考模式下 `temperature` 是无效的。不是报错，是静默忽略——你设了 0.4，它当没看见。如果你发现「调了温度，输出风格却没变」，八成是这个。

---

## 五、下次换模型前，我会照这张清单走一遍

把上面几个坑收成一张单子。

模型还在不在官方列表上——不在就先迁移，别在要下线的模型上做优化。思考开没开、在第几档——默认是「开启 + 最高档」，不是「关着」。`max_tokens` 够不够思考和正文一起花——一步给足，建议 ≥8000，别按你预期的正文长度设。采样参数还生效吗——思考模式下 `temperature` 会被静默忽略。最后，按用途分档别一刀切，改了强度就得同步放宽超时。

最后这条我栽过：把周报的强度提到 `high` 之后，原来 120 秒的超时就不够看了，得放宽到 240 秒。改思考强度就要改超时，这两个是绑在一起的。

---

上面这些数字都是 2026-10-16 的实测。模型列表和价格随时会变，参数值别照抄。

但下次你准备换模型的时候，可以先问自己一句：我现在用的这个，还在官方列表上吗？

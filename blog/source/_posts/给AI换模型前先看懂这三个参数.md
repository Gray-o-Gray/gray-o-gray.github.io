# 给 AI 换模型前，先看懂这三个参数

先说结论：我给自家的 AI 教练换了个「更强」的模型，它从秒回变成了要等 100 秒。

<!-- more -->

查了一圈才发现，问题根本不在模型选得对不对，而在三个参数我从来没认真看过：**思考模式的开关、思考强度的档位、以及一个会把你的正文悄悄吃掉的额度上限**。

这三个参数不是 DeepSeek 独有的概念，绝大多数带推理能力的模型服务都有对应的东西。所以这篇不讲「哪家模型强」，只讲换模型之前该看什么。

---

## 一、第一步不是换模型，是查模型还在不在

我的 AI 教练一直用 `deepseek-chat`，用了几个月，稳定。

出问题那天我想让它「想得更深一点」，就把它换成了 `deepseek-reasoner`（推理模型）。确实变强了——回答里开始出现我以前没见过的交叉核对——但单轮耗时从几秒变成了**大约 100 秒**。

我去翻官方文档，看到的不是调参建议，而是这么一件事：

> 官方模型列表里只剩 `deepseek-flash` 和 `deepseek-v4-pro`。`deepseek-chat` 和 `deepseek-reasoner` 都已经不在列表上了。

也就是说，我一直在用的默认模型，以及我刚换上去的推理模型，都属于「还能调、但已经不在名单里」的状态。

这件事给我的触动比慢 100 秒更大：**AI 服务的默认配置是有保质期的。** 你写进代码里的那个模型名，不会有人通知你它下线，只会某天开始变慢、变贵、或者干脆报错。

所以换模型之前的第一步，不是比较谁更强，而是去官方的 Models & Pricing 页面看一眼：我现在用的这个，还在不在。

---

## 二、参数一：thinking——思考是个开关，不是一种模型

我以前的认知是：想要推理能力，就得换推理模型。

现在的做法不是这样了。思考模式是一个**开关**，跟模型解耦：

```json
"thinking": { "type": "enabled" }   // 开启
"thinking": { "type": "disabled" }  // 关闭
```

而且它**默认是开启的**。

这意味着一件很容易被忽略的事：你觉得自己一直在用「普通模型」，其实它可能一直在思考，只是你没注意——相应的延迟和 token 消耗也一直在发生。

所以「我这个调用到底有没有在思考」不能靠猜，得看参数。

---

## 三、参数二：reasoning_effort——想要弱一点的推理，调档就行

这是解决我那 100 秒的关键。

既然思考是分档的，那「我想让它想，但别想那么久」就有了解法——不用在「思考」和「不思考」之间二选一：

```json
"reasoning_effort": "low"   // 轻量思考
"reasoning_effort": "high"  // 默认档
"reasoning_effort": "max"   // 最重
```

（官方还接受一些别名，`minimal` 归到 `low`，`medium` / `xhigh` 归到 `high`，`ultra` 归到 `max`。）

我拿同一个问题、同样约 11k 字符的上下文实测了一遍：

| 配置 | 单轮耗时 |
|------|---------|
| `deepseek-reasoner`（我一开始换的） | 约 100 秒 |
| `deepseek-flash` + `reasoning_effort: low` | 约 10 秒 |
| `deepseek-flash` + `reasoning_effort: high` | 约 9 秒 |
| `deepseek-flash` + 关闭思考 | 最快 |

注意最后两行：在这道题上，`low` 和 `high` 的耗时几乎一样。也就是说**强度档位不是线性的「越慢越强」**，简单问题拉开不出差距，复杂问题才会。

我最后的做法是**按用途分档**，而不是全局统一：

| 用途 | 强度 | 理由 |
|------|------|------|
| 教练对话（自由问答，判断型） | high | 要交叉核对，愿意多等 |
| 每周分析（周报 + 下周计划） | high | 跨多天数据权衡，本来就要跑一两分钟 |
| 按天反馈（每天自动跑） | low | 频次高，快比深重要 |

这套分档比「统一换一个更强的模型」有效得多。

---

## 四、参数三：max_tokens——思考和正文，共用同一份额度

这是三个参数里最容易踩、也最难自查的一个。

我调参时试过把 `max_tokens` 设成 1500，想着「我只要几百字的答案，够了」。结果返回的答案是**空的**。

我去看返回内容，发现思考部分用了 **2322 个 token** —— 已经超过我设的 1500 上限，额度被思考吃光了，正文一个字都没轮到输出。

关键规则只有一句：

> **思考 token 计入 `max_tokens`。** 你给的上限是「思考 + 正文」的总和，不是正文的长度。

所以如果你遇到「AI 明明在运转，最后却什么都没说」，先别怀疑提示词，去看看 `max_tokens` 是不是给小了。我现在的做法是**直接给到 8000**，反正上限只是封顶，不意味着每次都会用满。

顺带一个同源的坑：**思考模式下，`temperature` 是无效的**。不是报错，是静默忽略——你设了 0.4，它当作没看见。如果你发现「调了温度但输出风格没变」，八成是这个原因。

---

## 五、换模型前的五步自查

把上面的坑收成一张清单，下次换模型或升级 AI 服务时照着走一遍：

1. **模型还在不在官方列表上**——不在的话，先迁移再优化，别在要下线的模型上做调参
2. **思考模式开没开、强度在第几档**——默认是「开启 + 最高档」，不是「关闭」
3. **`max_tokens` 够不够思考和正文一起用**——建议一步给足（≥8000），别按预期正文长度设
4. **采样参数还生效吗**——思考模式下 `temperature` 会被静默忽略，别指望它调风格
5. **按用途分档，别一刀切**——对话类可以深，批量类要快；改了强度记得同步放宽超时

第 5 条我吃过亏：把周报的强度提到 high 之后，原来 120 秒的超时就不够看了，得同步放宽到 240 秒。**改了思考强度，就要改超时**，这两个是绑在一起的。

---

最后说明一句：本文所有数字都是 2026-10-16 的实测结果，模型列表和价格随时会变，别直接抄参数值。

但上面这五步不会变。AI 服务在快速迭代，你今天写进代码的默认值，保质期可能只有几个月——比起记住某个模型名，不如记住怎么查。
